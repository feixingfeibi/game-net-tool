游戏网络工具箱 - 使用说明
========================

功能
----
1. 选择运行中的游戏进程
2. 完全断网 / 仅禁上行 / 仅禁下行
3. 自定义速度限制 (上行/下行独立设置)
4. 全局快捷键 (默认 Ctrl+F9) 一键开关

环境要求
--------
- Windows 10/11
- Python 3.10+ (打包后无需)
- 管理员权限 (程序启动时自动请求)

安装步骤
--------
方式一: 直接运行 Python
  1. pip install -r requirements.txt
  2. python main.py (会自动请求管理员权限)

方式二: 打包为 exe
  1. 双击 build.bat
  2. 生成的 exe 在 dist/GameNetTool.exe

速度限制功能 (可选)
-------------------
速度限制依赖 WinDivert 驱动:
  1. 从 https://reqrypt.org/windivert.html 下载 WinDivert
  2. 将 WinDivert.dll 和 WinDivert64.sys 放到程序同目录
  3. pip install pydivert (如果用 Python 运行)

注: 不安装 WinDivert 时，封锁功能 (断网/禁上行/禁下行) 仍然可用

使用方法
--------
1. 启动程序 (会请求管理员权限)
2. 在进程列表中搜索并选择目标游戏
3. 选择控制模式:
   - 完全断网: 禁止所有网络通信
   - 仅禁上行: 只禁止上传
   - 仅禁下行: 只禁止下载
   - 自定义速度: 分别设置上行/下行速度 (KB/s)
4. 点击 "启用" 或按 Ctrl+F9
5. 点击 "停止" 或再按 Ctrl+F9 恢复

快捷键
------
默认: Ctrl+F9 (切换开关)
可在界面中自定义修改，输入后点击 "应用"

原理说明
--------
- 封锁模式: 通过 Windows 防火墙添加规则阻止指定程序的网络访问
- 限速模式: 通过 WinDivert 拦截数据包，用令牌桶算法控制传输速率
- 程序关闭时自动清理所有防火墙规则
